How to Use

Use the tabs to switch between creating a PK3 from a folder and extracting a PK3 back into a zip of files. All work is done locally in your browser.

  1. To create a PK3: go to Create PK3, select your folder (or drag files), optionally add WADs, then click Create PK3 File.
  2. To extract a PK3: go to Extract PK3, choose a PK3 file (or drag it in), then click Extract to ZIP.
