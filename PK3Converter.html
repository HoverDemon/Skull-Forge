How to Use

PK3 files are ZIP archives used by modern Doom engines like GZDoom. This tool helps you package your game files.

  1. Select your game folder - Click the first upload area or drag your folder containing all game files (textures, sounds, scripts, etc.)
  2. Add WAD files (optional) - If you have map files in WAD format, add them here. They'll go in a maps/ folder.
  3. Review the file list - Make sure all your important files are shown.
  4. Create the PK3 - Click "Create PK3 File" to package everything.
  5. Download - Your browser will download the PK3 file when complete.

Note: All processing happens in your browser. No files are uploaded to any server.
