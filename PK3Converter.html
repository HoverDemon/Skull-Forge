📝 Instructions

PK3 files are ZIP archives used by ZDoom to package game assets. This tool allows you to convert a folder of assets into a PK3 file.

  1. Click on the upload area or drag a folder containing your game assets
  2. Optionally, add WAD files (they will be placed in a maps folder)
  3. Make sure you are inside the correct folder before clicking "Create PK3 File"
  4. Click "Create PK3 File" to generate your package
  5. Once processing is complete, your browser will download the PK3 file

Note: Folder structure is preserved inside the PK3 file. This tool runs entirely in your browser.
