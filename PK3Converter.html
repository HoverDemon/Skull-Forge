📝 Instructions

PK3 files are ZIP archives used by ZDoom to package game assets. This tool allows you to convert a folder of assets into a PK3 file.

  1. Click on the upload area or drag a folder containing your game assets
  2. Review the list of files to be included in your PK3 archive
  3. In this case the folder should be /Github/Skull-Forge/Skull Forge Alpha 2.0
  4. Make sure youre inside teh folder before clicking "Send"
  5. Click "Create PK3 File" to generate your package
  6. Once processing is complete, your browser will download the PK3 file

Note: Due to browser security restrictions, you need to select files through the folder picker. The folder structure will be preserved in the PK3 file.
